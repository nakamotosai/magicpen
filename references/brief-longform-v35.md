# 长文 brief 合同 · v3.5（防同构 / 防提纲）

> 人生评、阶段评、长评传类 **默认** 用本模板。短评/单场面可跳过分节。

## 必写

1. **字数区间**（如 1800–2600）
2. **题目 + 角度**（判断全文最多点 1 次，禁节末刷屏）
3. **开篇合同**（硬）：
   - 先写被什么撞到（群/私信/热搜）
   - 再写自己查了什么
   - 再下判断
4. **阶段清单**（事实节点），**不要**写成固定隐喻节题
5. **结构**：`## 一、`… 自拟标题；覆盖阶段即可
6. **禁止**：破折号（若人格要求）；content_ban 事件；经营广告；焊死 船/漆/镜/账本 为六节标题

## 禁止写法

```
## 一、从奈良出来的鼓手
## 二、进了自民，傍上了安倍这条船
## 五、上位之后：漆刷厚了，路却窄了
## 六、铁娘子的镜面
```

→ 易导致篇篇同构。改为阶段 bullet，让 Writer 自拟节题。
