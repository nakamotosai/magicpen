# magicpen —— 神笔马良トゥルークローン執筆フロー

> 内容は神笔马良（Shenbi Maliang）そのものである。

トゥルークローン執筆フロー：人手を加えずに「本人が書いたように読める」原稿を書く。

## 仕組み

1. **人格パック三束ベースライン。**文体（A：文長/口癖/人称/句読点）、思考（B：五段構成/書き出し/比喩ルール）、
   判断（C：立場/禁忌/執筆ルール）。三束は長文コーパスの層別抽出（A：30 編 / B：30 編 / C：31 編）に基づく数値で、
   `profile/` に収録——本リポジトリに原文は含まない。
2. **内部 task 自己ループ、唯一の正道。**書き手が起草し、機械チェックが事前スクリーニングを行い、
   三つの主観レーンが審査し、修正役が直す。最大 3 ラウンド。書く・験す・直すは常に別個の分身で、
   毎ラウンド空のコンテキストで再割当する。
3. **主観三レーン験稿。**文体審美・思考審美・判断審美が原稿を肉眼で読み、原文を引用する。
   験稿分身のスクリプト実行は禁止——機械は数えられても「この一文は無理やりだ」とは見抜けない。

合格ライン：`blocker = 0` かつ `major ≤ 1`、C 判断束に major なし、主観 A/B/C に FAIL なし。
機械 PASS でも主観 FAIL なら主観を優先する。

## ファイル

| パス | 説明 |
|---|---|
| `SKILL.md` | 唯一の入口：制約（§2–§4）、ワークフロー（§5）、ファイルマップ（§7） |
| `VERIFIER-PROMPTS.md` | 4 験稿ロールのプロンプト（機械事前審査 1＋主観審美 3） |
| `profile/profile_a.json` | A 文体数値ベースライン（文長/口癖/人称/句読点） |
| `profile/profile_b.json` | B 思考テンプレート（五段/書き出し/失敗ゲート） |
| `profile/stance_table.json` | C 立場 S-01…S-10（id / domain / stance / evidence / boundary） |
| `profile/taboo_list.json` | C 禁忌 T-01…T-10（ゼロトレランス） |
| `profile/decision_rules.json` | C 執筆ルール D-01…D-10 |

## 使い方

skill と内部サブエージェントを備えたエージェントで使う：

1. 書き手の起動時に `profile/` 五点と `SKILL.md` §2–§4 を必ず読む。
2. 話題から起草し、五段（事件アンカー → 範囲限定 → 分点ノウハウ → 感想と忠告 → 読者招待）に従う。
3. `VERIFIER-PROMPTS.md` の四ロール（機械事前審査＋主観 A/B/C）を回し、合格ラインまで修正する。
