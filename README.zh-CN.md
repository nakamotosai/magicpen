# magicpen —— 神笔马良真克隆写作流

> 公开仓沿用 **magicpen** 之名，内容即**神笔马良**。

真克隆写作流：零人工改写，也能写出"像本人写的"稿子。

## 怎么跑

1. **人格包三束基线。**风格（A：句长/口头禅/人称/标点）、思维（B：五段结构/起手/类比规则）、
   判断（C：立场/雷区/起草动作）。三束基线全部来自长文语料分层抽样（A：30 篇 / B：30 篇 / C：31 篇），
   数值见 `profile/`——本仓不带任何原文。
2. **内部 task 自循环，唯一正道。**写手分身按话题起草，机检分身快筛预检，主观三路亲眼验稿，
   修稿分身返修，最多 3 轮。写、验、修永远是不同分身，每轮空上下文重派。
3. **主观三路验稿。**风格审美、思维审美、判断审美逐句亲眼读稿并引用原文。
   验稿分身禁止跑脚本——机检只能数数，数不出"这句是硬凑的"。

通过线：`blocker = 0` 且 `major ≤ 1`，C 判断束无 major，主观 A/B/C 均无 FAIL。
机检 PASS 但主观 FAIL，以主观为准。

## 文件

| 路径 | 说明 |
|---|---|
| `SKILL.md` | 唯一入口：约束（§2–§4）、工作流（§5）、文件地图（§7） |
| `VERIFIER-PROMPTS.md` | 四个验稿角色提示词（1 机检预检 + 3 主观审美） |
| `profile/profile_a.json` | A 风格数值基线（句长/口头禅/人称/标点） |
| `profile/profile_b.json` | B 思维模板（五段/起手/失败门） |
| `profile/stance_table.json` | C 立场 S-01…S-10（id / domain / stance / evidence / boundary） |
| `profile/taboo_list.json` | C 雷区 T-01…T-10（零容忍） |
| `profile/decision_rules.json` | C 起草动作 D-01…D-10 |

## 用法

配合支持 skill + 内部子代理的 Agent 使用：

1. 写手分身启动时必读 `profile/` 五件 + `SKILL.md` §2–§4。
2. 按话题起草，遵循五段（事件锚 → 范围限定 → 分点干货 → 感想忠告 → 互动收尾）。
3. 按 `VERIFIER-PROMPTS.md` 跑四角色（机检预检 + 主观 A/B/C），修稿返修直到通过线。
